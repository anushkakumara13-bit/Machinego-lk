## 🚀 How to Run - මුල ඉඳලා

### Snack Expo (Phone එකෙන්ම)

1. Go to: `snack.expo.dev`
2. Create New Snack
3. **Dependencies Add කරන්න:**
   - Search `expo-location` -> Add `~18.0.0`
4. `App.js` එකේ මේ Repo එකේ Full Code එක Paste කරන්න
5. Save -> Auto Run!
6. Phone එකේ Expo Go App එකෙන් QR Scan කරන්න

### Local Run

```bash
git clone https://github.com/anushkakumara13-bit/Machinego-lk.git
cd Machinego-lk
npm install
npx expo install expo-location
npx expo start
